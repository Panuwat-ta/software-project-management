# การประเมินคุณภาพซอฟต์แวร์ตามมาตรฐาน ISO/IEC 25010
**ระบบที่ถูกประเมิน:** ระบบบริหารคลังสินค้าเดิม (`app_v1.py`) ที่ใช้ไฟล์ JSON ในการเก็บข้อมูล

| ลักษณะคุณภาพ (Quality Characteristics) | คะแนน (1-5 ดาว) | เหตุผลประกอบการประเมิน (Justification) |
| :--- | :---: | :--- |
| **1. Functional Suitability** (ความเหมาะสมของฟังก์ชัน) | ⭐⭐ | ระบบทำงานพื้นฐานได้ (ดูรายการ, เพิ่ม/ตัดสต็อก) แต่ยังขาดฟีเจอร์สำคัญ เช่น ระบบสมาชิกส่วนลด หรือการป้องกันการใส่ตัวเลขติดลบ |
| **2. Performance Efficiency** (ประสิทธิภาพการทำงาน) | ⭐⭐⭐ | เนื่องจากใช้งานแบบ File-based JSON กับข้อมูลขนาดเล็กจึงทำงานได้เร็ว แต่ในระยะยาวเมื่อข้อมูลเยอะขึ้น การโหลดและเซฟใหม่ทั้งหมดจะทำให้ระบบช้าและกินหน่วยความจำมาก |
| **3. Compatibility** (ความเข้ากันได้) | ⭐⭐⭐ | เขียนด้วย Python ซึ่งรันได้ข้ามแพลตฟอร์ม แต่ไม่มีการเปิด API เพื่อเชื่อมต่อกับระบบอื่น |
| **4. Usability** (ความน่าใช้งาน) | ⭐⭐ | เป็นหน้าจอ CLI (Command Line Interface) ขาดความสวยงาม ใช้งานยากสำหรับคนทั่วไป และยังไม่มี Input Validation ที่ดี ทำให้โปรแกรมหลุดได้ง่าย |
| **5. Reliability** (ความน่าเชื่อถือ/เสถียรภาพ) | ⭐ | เสี่ยงต่อการสูญหายของข้อมูลมาก เพราะไม่มี Transaction (Commit/Rollback) หากโปรแกรมหยุดชะงักระหว่างบันทึกไฟล์ ไฟล์ JSON อาจพัง (Corrupted) ทันที |
| **6. Security** (ความปลอดภัย) | ⭐ | ไม่มีการยืนยันตัวตน (Authentication) หรือควบคุมสิทธิ์การเข้าถึง (Authorization) และข้อมูลทั้งหมดถูกเก็บเป็นข้อความธรรมดา (Plain-text) |
| **7. Maintainability** (การบำรุงรักษา) | ⭐⭐ | โค้ดทั้งหมดรวมอยู่ในไฟล์เดียว (Monolithic) ไม่แยกส่วน (Separation of Concerns) และการตั้งชื่อตัวแปรบางส่วนไม่เป็นตามมาตรฐาน PEP 8 ทำให้แก้ไขดัดแปลงได้ยาก |
| **8. Portability** (ความสามารถในการพกพา/เคลื่อนย้าย) | ⭐⭐⭐⭐ | สามารถย้ายไปรันบนระบบปฏิบัติการใดก็ได้ (Windows, macOS, Linux) เพียงแค่มี Python ติดตั้งอยู่ |

**บทสรุปการประเมิน:** 
ระบบเดิม (As-is) ได้คะแนนต่ำมากในด้าน Reliability, Security และ Maintainability ซึ่งเป็นข้อบ่งชี้สำคัญว่าโครงสร้างสถาปัตยกรรมเดิมถึงขีดจำกัดแล้ว จำเป็นต้องได้รับการปรับปรุง (Refactoring) ไปสู่ระบบฐานข้อมูล (SQLite) และการออกแบบที่แยกส่วน (Modular/OOP) ตามที่วางแผนไว้ใน To-be Architecture
