พัฒนาระบบจ่ายสินค้า ตรรกะคำนวณส่วนลด และกำหนดบทบาทการทำงานในทีม (RACI)

1. เป้าหมายสัปดาห์ที่ 3 (Phase 3)

Discount Engine
เพิ่มตรรกะสำหรับการคิดคำนวณส่วนลดเมื่อผู้ใช้ซื้อสินค้า โดยอิงจากระดับสมาชิกระบบ (Tier)
Checkout Process
ปรับปรุงฟังก์ชันการทำรายการขายให้สามารถแสดงรายละเอียดการคิดเงินก่อนหักสต็อก และยืนยันผลลัพธ์ที่ชัดเจน
Team Management
กำหนดบทบาทในการทำงานร่วมกันโดยใช้ RACI Matrix และตั้งมาตรฐาน Definition of Done (DoD)

2. มาตรฐานการพัฒนา (Definition of Done)

  1. Automated Tests: ผ่านการทดสอบ PyTest 100% ไม่มี FAIL/ERROR
  2. Code Standards: เขียนโค้ดแบบ OOP และตั้งชื่อตัวแปรตามมาตรฐาน PEP 8
  3. Error Handling: ดักจับข้อผิดพลาด Input อย่างรัดกุมก่อนส่งต่อเข้า Business Logic
  4. Code Review: ได้รับการตรวจสอบและอนุมัติ (Approve) ผ่าน Git Workflow

3. บทบาทหน้าที่ในทีม (RACI Matrix)

ภานุวัฒน์ (PM/Dev)
Responsible (R) / Accountable (A): จัดทำ Project Charter, ร่างขอบเขตงาน, และพัฒนาฟีเจอร์หลัก (Discount Logic, Safe Save)
เอกพันธ์ (QA)
Responsible (R): ออกแบบ Test Case และเขียน Unit Tests (PyTest) สำหรับระบบจัดการคลังและส่วนลด
ณฐภาพ (Tech Lead)
Consulted (C) / Accountable (A): ให้คำแนะนำด้านสถาปัตยกรรม (MVC) ตรวจรับ Approve โค้ด และดูแลเรื่อง Code Merging

4. โครงสร้างตรรกะการคิดส่วนลด (Discount Engine)

ตัวอย่างลำดับขั้นในการจ่ายเงินและคิดส่วนลด

# Discount Logic Flow
1. รับรหัสสินค้า (Product ID) และจำนวนที่ต้องการซื้อ
2. ตรวจสอบสต็อกคงเหลือ (if qty <= stock)
3. ตรวจสอบรหัสสมาชิก (Member ID)
4. หากมี Member -> คำนวณส่วนลดตาม Tier (เช่น Gold 10%, Silver 5%)
5. สรุปยอดรวม (Total Price = Base - Discount)
6. ยืนยันการชำระเงิน -> ตัดสต็อกและบันทึกข้อมูล (Safe Atomic Write)
