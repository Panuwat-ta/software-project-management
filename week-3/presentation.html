1. ตรรกะการคิดส่วนลด (Discount Logic Engine)

# Discount Logic Flow (Pseudo-code)
def process_checkout(product_id, qty, member_id):
    if qty > product_stock: 
        return "Error: Not enough stock!"
        
    member = find_member(member_id)
    discount_rate = 0
    if member.tier == 'Gold': discount_rate = 0.10
    elif member.tier == 'Silver': discount_rate = 0.05
    
    total = base_price - (base_price * discount_rate)
    return proceed_to_payment(total)

ระบบจะแสดงยอดเงินสุทธิให้ยืนยันก่อน แล้วจึงทำการตัดสต็อก (Cut Stock)
