Week 3

Implementation & Testing

ลงมือพัฒนาโค้ดใหม่และการทดสอบ

การพัฒนาเวอร์ชันใหม่ (app_v2.py) และเขียนระบบทดสอบอัตโนมัติ (Automated Testing)

1. การปรับโครงสร้างโค้ด (Refactoring)

การปรับปรุงโค้ดใหม่ให้เป็น Object-Oriented Programming (OOP)

  • ลดการพึ่งพาตัวแปร Global ด้วย Class Structure
  • เพิ่ม Input Validation และ Exception Handling
  • ปรับใช้งาน Atomic Write บันทึกไฟล์ปลอดภัยขึ้นชั่วคราว

2. Automated Testing

PyTest & Unittest

รันสคริปต์ test_app.py และ test_app1.py เพื่อทำ Unit Testing ในทุกฟังก์ชัน

JSON Reports

สกัดรายงานผลลัพธ์การทดสอบออกมาในรูปแบบ JSON อัตโนมัติ (test.json)

3. สิ่งที่พัฒนาใน app_v2.py

Product & InventoryManager

จัดเก็บข้อมูลสินค้าเป็นวัตถุ แยกการโหลด บันทึก เพิ่ม/แก้ไข ตัดสต็อก และสรุปคลังสินค้า

InventoryCLI

แยกส่วนรับข้อมูลและการแสดงผล พร้อมตรวจสอบจำนวนและราคาก่อนประมวลผล

Data Integrity

ใช้ไฟล์ชั่วคราวและ os.replace เพื่อบันทึก JSON แบบ Atomic Save

Maintainability

ใช้ชื่อที่สื่อความหมาย, Type Hints และ Docstrings เพื่อให้ดูแลโค้ดต่อได้ง่าย

4. การทดสอบที่ครอบคลุม

กรณีทดสอบสิ่งที่ยืนยัน
Inventory summaryจำนวนประเภทสินค้า มูลค่ารวม และรายการสต็อกต่ำ
Cut stockตัดสำเร็จ, จำนวนไม่พอ และไม่พบรหัสสินค้า
Add / Updateเพิ่มสินค้าใหม่และแก้ไขสินค้าเดิมได้ถูกต้อง
JSON reportบันทึกผล PASS/FAIL/ERROR ลง test.json

5. การควบคุมคุณภาพทีม

ใช้ RACI และ Definition of Done เพื่อให้ทุกงานมีผู้รับผิดชอบและเกณฑ์ส่งมอบที่ชัดเจน

  • Developer: พัฒนาและปรับโครงสร้างโค้ด
  • QA / Tester: รับผิดชอบ Automated Test
  • Tech Lead: อนุมัติการรวมโค้ดและรับผิดชอบผลลัพธ์สุดท้าย
  • DoD: Tests ผ่าน, โค้ดได้มาตรฐาน, ปลอดภัย, เอกสารครบ และผ่าน Code Review
