Architecture & Governance

การออกแบบสถาปัตยกรรมและกลไกการบริหารโปรเจคเชิงลึก

เจาะลึกการอัปเกรดระบบสู่ SQLite และ Design Patterns,
การวางมาตรฐานการสื่อสาร (DoR/DoD),
และการบริหารจัดการงบประมาณแบบ Earned Value Management (EVM)

1. สถาปัตยกรรมเป้าหมาย (To-Be Architecture)

การเปลี่ยนผ่านจาก Monolithic JSON ไปสู่สถาปัตยกรรมแบบ Modular อาศัย 3 องค์ประกอบหลัก:

Database & Repository

  • SQLiteDatabaseContext: ใช้ Singleton Pattern ควบคุมให้มี Connection เดียว ป้องกันปัญหา Database Locked
  • InventoryRepository: หุ้มคำสั่ง SQL ทั้งหมด บังคับใช้ Parameterized Query เพื่อป้องกัน SQL Injection โดยสมบูรณ์

Member Tier Strategy

  • ใช้ Strategy Pattern ในการคำนวณส่วนลดแยกตามระดับ (Regular, Silver, Gold, Platinum)
  • ขจัดปัญหา Code Smell ประเภท if-else ซ้อนทับกันยาวเหยียดในหน้า Checkout
  • รองรับการสเกล (Scalability) เพื่อเพิ่มระดับสมาชิกใหม่ในอนาคตได้ทันที

2. มาตรฐานการทำงาน (DoR / DoD)

เพื่อควบคุมคุณภาพงานในทีมที่มี PM, QA และ Tech Lead เราใช้ Trello ควบคู่กับกฎเหล็กดังนี้:

เกณฑ์ควบคุมเงื่อนไขความสำเร็จแบบละเอียด
Definition of Ready (DoR)
(ก่อนเริ่มเขียนโค้ด)
  • การ์ดงานมีรายละเอียด (Description) อธิบายฟีเจอร์ชัดเจน
  • ประเมินและระบุความเสี่ยง/จุดกระทบ (Hotspots) เรียบร้อย
  • มอบหมายตัวบุคคลรับผิดชอบ (Assignee) ตาม RACI
  • แตก Branch ใหม่จาก develop ใน GitHub พร้อมทำงาน
Definition of Done (DoD)
(ก่อนย้ายงานสถานะ Done)
  • ผ่านกระบวนการ Code Review อย่างเข้มงวดโดย Tech Lead
  • สคริปต์ test_app.py (ของ QA) ต้องรันผ่าน 100% บน Automated Pipeline
  • โค้ดถูก Merge เข้าสู่ develop โดยไร้ข้อขัดแย้ง (Conflicts)

3. การวิเคราะห์ผลต่างงบประมาณ (Cost Variance - EVM)

การใช้ข้อมูลจริงในการแก้ไขปัญหาโครงการงบประมาณบานปลาย (Over Budget):

ปัญหาที่พบ (The Variance)

  • งาน: ย้ายฐานข้อมูล JSON -> SQLite
  • Planned (ตั้งงบ): 6 ชม. (2,400 บาท)
  • Actual (ใช้จริง): 10 ชม. (4,000 บาท)
  • สาเหตุ: โค้ดเก่าซับซ้อนเกินคาด ต้อง Refactor โครงสร้างก่อนถึงจะต่อ Database ได้
  • Cost Variance: -1,600 บาท (Over Budget)

วิธีแก้ไข (Management Action)

  • แจ้งเตือนทีมถึงความเสี่ยงสถานะการเงินของโปรเจค
  • PM: อนุมัติเบิกเงินสำรองฉุกเฉิน (Contingency Reserve) ที่ตั้งไว้ 15% มาโปะส่วนต่างทันที
  • Tech Lead: ปรับ Blueprint สำหรับรอบหน้าให้วิเคราะห์ Hotspot ให้ลึกขึ้น ป้องกันการประเมินเวลาพลาด
