Week 4

Testing & Code Refinement

การทดสอบและการแก้ไขปรับปรุงโค้ดขั้นสุดท้าย

ตรวจสอบความถูกต้องและประสิทธิภาพของระบบก่อนนำไปใช้จริง

1. Code Refinement

ยืนยันโครงสร้างสุดท้ายของระบบใน app.py

  • แยก Product, InventoryManager และ InventoryCLI ตามหน้าที่
  • ตรวจสอบข้อมูลนำเข้าก่อนเพิ่มสินค้า ตัดสต็อก และคำนวณราคา
  • บันทึกไฟล์ JSON ด้วย Atomic Save และระบุ UTF-8

2. Final Testing

ทำ System Testing แบบครบวงจรและสรุปผล

รายงานการทดสอบ

รวบรวมหลักฐานและภาพหน้าจอการทดสอบว่าผ่านทุกฟังก์ชัน

3. ขอบเขตการทดสอบ

ฟังก์ชันหลัก

ทดสอบสรุปคลังสินค้า การเพิ่ม/แก้ไข และการตัดสต็อก

กรณีขอบเขต

ทดสอบจำนวนสินค้าไม่พอ และรหัสสินค้าที่ไม่มีอยู่ในระบบ

ความถูกต้องของข้อมูล

ยืนยันมูลค่ารวมของคลังสินค้าและจำนวนคงเหลือหลังตัดสต็อก

หลักฐาน

มีสคริปต์ test_app.py และภาพผลการทดสอบ test_app.png

4. ผลลัพธ์ที่พร้อมส่งต่อ

ด้านผลการปรับปรุง
โครงสร้างโค้ดแยกความรับผิดชอบและทดสอบได้ง่ายขึ้น
เสถียรภาพจัดการ Input ผิดพลาดและป้องกันข้อมูลเสียหายระหว่างบันทึก
คุณภาพAutomated Test ครอบคลุมการทำงานปกติและกรณีผิดพลาด

5. เตรียมปิดโครงการ

นำผลการทดสอบและโค้ดเวอร์ชันสุดท้ายไปใช้จัดทำการประเมินคุณภาพ ISO/IEC 25010, เอกสารสถาปัตยกรรม และงบประมาณโครงการในสัปดาห์ที่ 5
