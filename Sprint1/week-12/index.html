1. รายงาน EVM ฉบับสุดท้าย (Final EVM Summary)

ข้อมูลสมมติเพื่อการเรียน · Fictional Educational Data

การกระทบยอดผลลัพธ์โครงการตลอด 3 Sprints (เอกสาร Final_EVM.md):

ตัวแปร EVM รายละเอียด มูลค่า / ดัชนี
Planned Value (PV) งบประมาณแผนงานรวมทั้งหมด (รวม CR-02) 15,525 บาท
Earned Value (EV) มูลค่างานที่ผ่าน DoD และเกณฑ์ทดสอบครบ 100% 15,525 บาท
Actual Cost (AC) ค่าแรงจริงจาก Log Time + ค่าเครื่องมือจริง 16,100 บาท
Schedule Performance Index (SPI) $SPI = EV / PV = 15,525 / 15,525$ 1.00 (ตรงเวลา 100%)
Cost Performance Index (CPI) $CPI = EV / AC = 15,525 / 16,100$ 0.96 (เกินงบ 3.7%)
Cost Variance (CV) $CV = EV - AC = 15,525 - 16,100$ -575 บาท (ชดเชยด้วยงบสำรอง)

การกระทบยอดงบสำรองความเสี่ยง: เริ่มต้น 2,823 บาท − คำขอฉุกเฉิน CR-02 (1,350 บาท) − ค่าแรงส่วนเกิน Refactoring (575 บาท) = คงเหลือสุทธิ 898 บาท (ไม่มีภาวะติดลบ งบประมาณโครงการควบคุมได้สมบูรณ์)

2. ผลการทดสอบการวิวัฒนาการ 25 Passed (Full Regression)

ชุดทดสอบ week-12/test_app.py ครอบคลุมการวิวัฒนาการของระบบครบถ้วน 25 กรณีทดสอบ:

  • 5 Baseline Tests: การคำนวณและตัดสต็อกดั้งเดิม
  • 4 CR-01 Tests: รหัสบาร์โค้ด และการคำนวณจุดสั่งซื้อขั้นต่ำ (Reorder Point)
  • 6 CR-02 Tests: การส่งออกไฟล์ CSV พร้อมหัวตารางที่ถูกต้อง
  • 4 BUG-101 Tests: การรับมือข้อมูลเก่าที่ไม่มีฟิลด์บาร์โค้ด (Legacy Compatibility)
  • 3 CLI Tests: การทำงานของส่วนติดต่อผู้ใช้
  • 3 Integration Tests: การทำงานร่วมกันระหว่างโมเดลและไฟล์ระบบ
