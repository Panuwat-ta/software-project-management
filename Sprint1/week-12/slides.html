TESTING & RELEASE ข้อมูลสมมติเพื่อการเรียน

25 Passed Tests และด่านตรวจรับระบบ

การทดสอบความถูกต้องของระบบและความพร้อมในการส่งมอบซอฟต์แวร์

ชุดทดสอบ Full Regression 25 รายการ
  • 5 Baseline Tests: การคำนวณและตัดสต็อกสินค้าแบบดั้งเดิม
  • 4 CR-01 Tests: รหัสบาร์โค้ด และการคำนวณ Reorder Point
  • 6 CR-02 Tests: การส่งออกไฟล์ CSV พร้อมหัวตารางที่ถูกต้อง
  • 4 BUG-101 Tests: การรับมือข้อมูลเก่าที่ไร้บาร์โค้ด (Backward Compatibility)
  • 3 CLI Tests + 3 Integration Tests: การทำงานร่วมกันระหว่างโมเดลและไฟล์
ด่านตรวจรับ UAT และสถานะ Release
  • UAT 3 Scenarios: รับสินค้า Milk, ตัดสต็อกจน Alert, และส่งออก CSV ใน Excel
  • สถานะ UAT Sign-off: จัดเตรียมเกณฑ์ครบถ้วน แต่ช่องลงนามทางการยังคงว่าง
  • สถานะ Git Release Tag: จัดทำ CHANGELOG.md ครบถ้วน แต่ยังไม่มีแท็ก v2.0.0 บน main
  • หนี้ทางเทคนิค: Flake8 E501 ยังเปิดอยู่ และ SQLite/Member ยังเป็นแบบออกแบบ
อ้างอิงเอกสาร: Release_Checklist.md และ UAT_Sign_Off_Sheet.md
