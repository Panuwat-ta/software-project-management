สัปดาห์ที่ 5: สถาปัตยกรรม คุณภาพ ISO 25010 และงบประมาณ

เปรียบเทียบสถาปัตยกรรมระบบ As-is vs To-be, ประเมินคุณภาพตามกรอบมาตรฐาน ISO/IEC 25010 และจัดทำแผ่นงานงบประมาณโครงการ (Budget Worksheet)

เปิดสไลด์ประกอบสัปดาห์ 5 →

1. สถาปัตยกรรมระบบ: เดิม vs เป้าหมาย (As-is vs To-be)

มิติการเปรียบเทียบ สถาปัตยกรรมเดิม (As-is) สถาปัตยกรรมเป้าหมาย (To-be Design)
รูปแบบโครงสร้าง Monolithic Script มัดรวม UI, Logic, Storage Clean Architecture แบ่ง 3 เลเยอร์ (Facade, Service, Repository)
การจัดการสถานะ Global Variable x และ db Encapsulated Classes (Product, ProductManager, DatabaseManager)
การจัดเก็บข้อมูล ไฟล์ JSON เดียว บันทึกทับทันที SQLite Database รองรับ ACID Transactions (Commit/Rollback)
ระบบสมาชิก ไม่มีระบบสมาชิก โมดูลสมาชิก 4 ระดับ (Regular, Silver, Gold, Platinum)

2. การประเมินคุณภาพตามมาตรฐาน ISO/IEC 25010

  • Maintainability (ความสามารถในการบำรุงรักษา): ยกระดับ Modularity ด้วยการแยกคลาส, เพิ่ม Analyzability โดยตั้งชื่อตัวแปรตาม PEP 8 และเพิ่ม Testability ด้วยการลด Global Coupling
  • Reliability (ความน่าเชื่อถือ): ป้องกัน Fault Tolerance ด้วย Try-Except Validation และเตรียม Transaction Rollback ป้องกันข้อมูลสูญหาย
