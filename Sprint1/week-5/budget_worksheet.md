# แผ่นงานงบประมาณโครงการ (Budget Worksheet)

เอกสารนี้แสดงการคำนวณงบประมาณของโครงการประยุกต์และปรับปรุงระบบบริหารคลังสินค้า โดยอ้างอิงจากการแบ่งงาน (WBS) ในระยะเวลา 5 สัปดาห์

## 1. รายการชิ้นงาน (Work Breakdown Structure: WBS) สำหรับการ Refactoring
เพื่อใช้ในการประเมินเวลาทำงาน (Man-Hours) และต้นทุนของแต่ละงาน:

| รหัสงาน | ชื่อชิ้นงาน (Task) | บทบาทที่รับผิดชอบ | เวลาประเมิน (ชม.) |
| :--- | :--- | :--- | :---: |
| WBS-01 | ออกแบบสถาปัตยกรรม To-Be และ Class Diagram | Tech Lead / Architect | 5 |
| WBS-02 | ตั้งค่าฐานข้อมูล SQLite และย้ายข้อมูลจาก JSON | Developer | 5 |
| WBS-03 | เขียนคลาส `DatabaseManager` (Singleton Pattern) | Developer | 4 |
| WBS-04 | สร้าง `ProductManager` เพื่อจัดการสต๊อกสินค้า | Developer | 4 |
| WBS-05 | สร้างระบบสมาชิกและส่วนลด `MemberSystem` | Developer | 4 |
| WBS-06 | ปรับปรุงระบบส่วนติดต่อผู้ใช้ `SystemCLI` (Facade Pattern) | Developer | 3 |
| WBS-07 | รวมระบบและทดสอบการทำงาน (Integration Testing) | QA / Tester | 10 |
| WBS-08 | ตรวจสอบคุณภาพโค้ดและทำเอกสารสรุปโครงการ | QA / Tester | 5 |
| **รวม** | | | **40** |

## 2. ต้นทุนค่าแรงทางตรง (Direct Labor Costs)
คำนวณชั่วโมงการทำงานจากบทบาทหน้าที่ในโครงการ คูณด้วยอัตราค่าจ้างรายชั่วโมง (อ้างอิงจาก WBS)

| บทบาท (Role) | ผู้รับผิดชอบ | อัตราค่าจ้าง (THB/ชม.) | เวลาโดยประมาณ (ชม.) | รวมค่าแรง (THB) |
| :--- | :--- | :---: | :---: | :---: |
| **Project Manager / Developer** | นาย ภานุวัฒน์ | 500 | 20 | 10,000 |
| **Tech Lead / Architect** | นาย ณฐภาพ | 600 | 25 | 15,000 |
| **QA / Tester** | นาย เอกพันธ์ | 400 | 15 | 6,000 |
| **รวมต้นทุนค่าแรง (Subtotal 1)** | | | **60** | **31,000** |

*(หมายเหตุ: ชั่วโมงทำงานประเมินจากการวางแผน, พัฒนา, ตรวจสอบโค้ด, และทำเอกสาร)*

## 3. ต้นทุนโครงสร้างพื้นฐาน (Infrastructure & Software Costs)
ค่าใช้จ่ายสำหรับเครื่องมือ ซอฟต์แวร์ และคลาวด์ตลอดระยะเวลาโครงการและการนำไปใช้งานจริงเบื้องต้น (ต่อรอบ 1 เดือน)

| รายการ (Item) | รายละเอียด | ค่าใช้จ่าย (THB) |
| :--- | :--- | :---: |
| **Cloud Database / Hosting** | บริการ Cloud (เช่น AWS EC2 ขนาดเล็ก หรือ DigitalOcean) สำหรับ Deploy ระบบ | 1,500 |
| **CI/CD Services** | บริการ Automated Test/Deploy (เกินโควต้าฟรีของ GitHub Actions) | 500 |
| **Software Licenses** | เครื่องมือเสริมสำหรับทีม (เช่น Trello Premium/Jira, IDE License) | 1,000 |
| **รวมต้นทุนโครงสร้างพื้นฐาน (Subtotal 2)** | | **3,000** |

## 4. สรุปงบประมาณรวม (Total Budget Summary)

| รายละเอียดค่าใช้จ่าย | จำนวนเงิน (THB) |
| :--- | :---: |
| ต้นทุนค่าแรงทางตรง (Direct Labor) | 31,000 |
| ต้นทุนโครงสร้างพื้นฐาน (Infrastructure) | 3,000 |
| **ต้นทุนรวมเบื้องต้น (Base Cost)** | **34,000** |
| **งบประมาณสำรองความเสี่ยง 15% (Contingency Reserve)** | **5,100** |
| **งบประมาณโครงการรวมทั้งสิ้น (Total Budget)** | **39,100** |

## คำแนะนำสำหรับการนำไปใช้ใน Trello (Trello Integration)
1. **การตั้งค่า Custom Fields**: แนะนำให้เพิ่มช่อง `Estimated Hours`, `Actual Hours`, และ `Cost/Budget` ลงในบอร์ด Trello 
2. **การลงบันทึกเวลา**: ให้สมาชิกแต่ละคนบันทึกชั่วโมงที่ใช้จริงลงในช่อง `Actual Hours` ของการ์ดแต่ละใบเมื่องานเสร็จสิ้น
3. **การนำข้อมูลเข้า Trello**: สามารถใช้สคริปต์ `update_trello.py` อ่านข้อมูลจากไฟล์เอกสารเพื่อยิงผ่าน API ไปอัปเดตช่องรายละเอียดในการ์ดต่างๆ แบบอัตโนมัติได้
