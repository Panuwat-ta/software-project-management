1. การวิเคราะห์จุดอันตราย (Dangerous Hotspots Analysis)

เอกสาร Hotspot.md ชี้เป้า 3 จุดวิกฤตที่มีการผูกมัดข้อมูลอย่างหนาแน่น (High Coupling) และเปราะบางสูงใน app_v1.py:

จุดอันตราย (Hotspot) ลักษณะปัญหาและความเสี่ยง แนวทางแก้ไขเชิงสถาปัตยกรรม
Hotspot 1: ตัวแปรโกลบอล x ทุกฟังก์ชันรุมอ่านเขียนข้อมูลใน x โดยตรง สกีมาไม่มีการป้องกัน (อ้างคีย์สั้น x[k]['n']) หากคีย์เปลี่ยนจะเกิด KeyError ทันที และทำให้เขียน Unit Test ไม่ได้ ครอบด้วยคลาส Product มี Type Annotation และจัดการผ่านคลาส InventoryManager
Hotspot 2: ฟังก์ชัน main() มัดรวมทุกสิ่ง มัดรวม UI, Business Logic และ Data Access ในบล็อก if-elif เดียว มี Cyclomatic Complexity สูงถึง 14 การแก้อาจเกิด Side-effects ได้ง่าย แยกเลเยอร์ตามหลัก Separation of Concerns ให้ main() รับผิดชอบเฉพาะหน้าจอ CLI
Hotspot 3: Direct Value Casting แปลง int(input()) และ float(input()) โดยไม่มี try-except ทำให้โปรแกรมแครชทันทีเมื่อกรอกผิด สร้าง Helper Method ตรวจสอบความถูกต้องและดักจับ ValueError

2. รายงานการวิเคราะห์ซอร์สโค้ดเชิงสถิต (Static Code Analysis)

ผลจากการตรวจสอบ app_v1.py ด้วยเครื่องมือ Pylint และ Radon ในเอกสาร Static-Analysis.md สรุปตัวชี้วัดได้ดังนี้:

ตัวชี้วัด (Metric) ค่าที่ตรวจพบในโค้ดเดิม การประเมินผล
Lines of Code (LOC) 99 บรรทัด (LLOC 77, SLOC 78, Comments 8) ขนาดเล็กแต่มีความหนาแน่นของตรรกะสูง
Pylint Score 7.10 / 10 มีข้อควรแก้ไขด้านระเบียบโค้ด PEP 8 หลายจุด
Complexity: main() CC = 14 (Grade C) ซับซ้อนปานกลางถึงสูง มีกิ่งเงื่อนไขแตกแขนงถึง 17 สาขา (R0912) และ 55 คำสั่ง (R0915)
Complexity: load() CC = 2 (Grade A) ความซับซ้อนต่ำ โครงสร้างเป็นเส้นตรง
Complexity: save() CC = 1 (Grade A) ความซับซ้อนต่ำ

3. พิมพ์เขียวสถาปัตยกรรมใหม่ (Refactoring Blueprint)

กำหนดโครงสร้างแบ่งเลเยอร์ 3 ชั้น (Three-Tier Architecture) เพื่อให้ระบบแยกหน้าที่ชัดเจน:

  • Presentation Layer (CLI Interface): รับอินพุต แสดงผลคอนโซล และตรวจสอบความถูกต้องของข้อมูล (Input Validation) ก่อนส่งต่อ
  • Domain Layer (InventoryManager): จัดเก็บตรรกะทางธุรกิจ เช่น การคำนวณมูลค่ารวม การลดจำนวนสต็อก และเงื่อนไขเตือนสต็อกต่ำ
  • Data Access Layer & Models (Product): คลาสแบบจำลองข้อมูลสินค้า และการบันทึกไฟล์ JSON แบบปลอดภัย
