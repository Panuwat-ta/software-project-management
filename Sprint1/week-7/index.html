สัปดาห์ที่ 7: ต้นทุนงบประมาณ (Cost Baseline) และคุณภาพ ISO 14598

อนุมัติต้นทุนงบประมาณอ้างอิง (Approved Cost Baseline), วางแผนความจุของทีม (Capacity Planning) และจัดทำรายงานประเมินคุณภาพ ISO/IEC 14598

1. ตารางสรุปงบประมาณสุทธิที่อนุมัติ (Cost Baseline)

ข้อมูลสมมติเพื่อการเรียน · Fictional Educational Data

เอกสาร Cost_Baseline_and_Sprint_Plan.md สรุปงบประมาณทางการของทีม 3 คนสำหรับช่วงการปรับปรุงระบบ:

หมวดหมู่ต้นทุน สัดส่วน (%) จำนวนเงิน (บาท)
ค่าแรงงานทางตรง (Direct Labor Cost) 80.0% 15,000
โครงสร้างพื้นฐานและเครื่องมือ (Infrastructure & Tooling) 5.0% 1,000
รวมต้นทุนทางตรง (Subtotal Direct Cost) 85.0% 16,000
งบสำรองเผื่อฉุกเฉิน (Contingency Reserve 15%) 15.0% 2,823
ยอดรวมงบประมาณที่อนุมัติ (Total Approved Budget Baseline) 100.0% 18,823

2. เกณฑ์การเฝ้าระวังงบประมาณและความจุทีม (Sprint 1 Capacity)

  • เกณฑ์ผลต่างงบประมาณ: ปกติ (0-5%), แจ้งเตือน (5-10% ประชุมหาทางลดเวลา), วิกฤต (>10% พิจารณาลดขอบเขตหรือดึงงบสำรอง)
  • การคำนวณกำลังการผลิต (Team Capacity): สมาชิก 3 คน × 6 ชม./สัปดาห์ × 2 สัปดาห์ = 36 Man-Hours (งานทั้งหมดใน Sprint ห้ามเกิน 36 Man-Hours โดยเด็ดขาด)

3. รายงานการประเมินคุณภาพ ISO/IEC 14598

อิงกรอบมาตรฐาน ISO 25010 ในด้าน Maintainability และ Reliability โดยกำหนดเป้าหมายเชิงปริมาณ:

ดัชนีชี้วัดคุณภาพ สถานะเดิม (app_v1.py) เป้าหมายที่คาดหวัง
Max Cyclomatic Complexity $v(G)$ สูงเกินเกณฑ์ (>20 กิ่งเงื่อนไข) แยกย่อยฟังก์ชัน $\le 8$
ความปลอดภัยของข้อมูล โปรแกรมแครชทันทีเมื่อกรอกตัวอักษร มีระบบดักจับ (Try-Except Validation)
การใช้ Global State พึ่งพา global x ทุกจุด ยกเลิก 100% เปลี่ยนเป็น Class Instances
Code Coverage 0% (ไม่มีสคริปต์เทสต์) ผ่านการทดสอบจาก test_app.py $\ge 85\%$

CI/CD Quality Gate: ทุก Pull Request บน GitHub Actions จะต้องผ่าน PyTest อัตโนมัติ หากไม่ผ่าน ปุ่มผสานโค้ดจะถูกล็อกทันที
