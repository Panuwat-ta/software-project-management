Week 1

Planning & Legacy Code Review

ขั้นวางแผนและทบทวนโค้ดดั้งเดิม

วิเคราะห์โครงสร้างโปรแกรมเดิมที่เป็น Monolithic JSON-based
ร่าง Project Charter และ Scope การทำงาน

1. กฎบัตรโครงการ (Project Charter)

👥 ทีมงานและบทบาท

  • PM / Developer: ภานุวัฒน์
  • Tech Lead: ณฐภาพ
  • QA / Tester: เอกพันธ์

🎯 เป้าหมายสัปดาห์ที่ 1

ทำความเข้าใจโค้ดดั้งเดิม app_v1.py และ data.json

2. โค้ดดั้งเดิม (Legacy Code)

ระบบเดิมเป็น CLI แบบ Monolithic และใช้ไฟล์ JSON เป็นที่เก็บข้อมูล

  • ใช้ตัวแปร Global ทำให้ตรวจสอบสถานะลำบาก
  • เก็บข้อมูลในไฟล์ JSON โดยขาดกลไกป้องกันข้อมูลสูญหาย (Atomic Save)
  • ตรรกะทั้งหมดอยู่ในไฟล์เดียว (Monolithic)

3. เป้าหมายและขอบเขต

In scope

  • แยก Business Logic ออกจาก CLI
  • ตรวจสอบข้อมูลนำเข้าและค่าติดลบ
  • บันทึกข้อมูลแบบ Atomic Write
  • สร้าง Automated Unit Tests

ข้อจำกัดในระยะแรก

  • คงรูปแบบการใช้งานเป็น CLI
  • ไม่พัฒนา GUI หรือ Web Application
  • รักษาพฤติกรรมหลักของระบบคลังสินค้าเดิม

4. ความเสี่ยงและแนวทางรับมือ

ความเสี่ยงผลกระทบแนวทาง
Refactor กระทบพฤติกรรมเดิมRegressionปรับทีละส่วนและรันชุดทดสอบทุกครั้ง
ข้อมูล JSON เดิมไม่ตรง Schemaอ่านข้อมูลไม่ได้ตรวจสอบและทำความสะอาดข้อมูลก่อนใช้งาน
ไม่มี Legacy Testsตรวจพบข้อผิดพลาดช้าจัดทำ Test Case ก่อนแก้โค้ดหลัก

5. ผลส่งมอบและก้าวถัดไป

ผลส่งมอบ

Project Charter, Scope, รายงานทำความเข้าใจระบบเดิม และแผนงานบน Trello

สัปดาห์ถัดไป

วิเคราะห์ Hotspot ออกแบบ Data Flow และ Blueprint สำหรับโครงสร้างที่ปรับปรุงแล้ว
