SQuaRE Framework คืออะไร?
SQuaRE (Software Product Quality Requirements and Evaluation) คือ ตระกูลมาตรฐานสากลที่ถูกพัฒนาขึ้นมาทดแทนมาตรฐาน ISO/IEC 9126 ดั้งเดิม

Quality in Use (มุมมองผู้ใช้งาน): ตรวจวัดประสิทธิภาพ ประสิทธิผล และความพึงพอใจเมื่อนำระบบไปรันจริง

แกนหลัก Maintainability คืออะไร?
วิกฤตของ Maintainability ต่ำ:
การแก้บั๊กย่อยจุดเดียว สร้าง Side Effects ลามพังทั้งระบบ
ต้นทุนการบำรุงรักษา (Maintenance Cost) พุ่งสูงขึ้นเป็นเท่าตัว

1. Modularity
การแยกส่วนโมดูลอิสระ High Cohesion & Low Coupling
2. Reusability
การนำฟังก์ชันย่อยกลับมาใช้ประโยชน์ซ้ำได้โดยไม่ต้อง copy-paste
3. Analyzability
ความง่ายในการวินิจฉัยจุดเสียและประเมินผลกระทบ
4. Modifiability
ความง่ายในการปรับเปลี่ยนแก้ไขโดยไม่เกิด Side Effects
5. Testability
ความสามารถในการตั้งเกณฑ์และรัน Unit Test อัตโนมัติ

REVERSE ENGINEERING ANALYSIS AS-IS ARCHITECTURE RECOVERY
แกะ Pattern ดั้งเดิม (Reverse Engineering)

รูปแบบทางแก้ปัญหา (Reusable Solutions) ที่ผ่านการทดสอบและยอมรับในอุตสาหกรรม แบ่งออกเป็น 3 หมวดหลักโดย Gang of Four (GoF):
1. Creational
จัดการกระบวนการสร้าง Objects อย่างปลอดภัยและยืดหยุ่น (เช่น Singleton, Factory)
2. Structural
จัดการการประกอบโครงสร้าง Class และ Objects ให้เป็นระบบ (เช่น Repository, Adapter)
3. Behavioral
จัดการการสื่อสาร พฤติกรรม และการมอบหมายหน้าที่ระหว่าง Objects (เช่น Strategy, Observer)
DESIGN PATTERN FUNDAMENTALS GANG OF FOUR (GOF) CATEGORIES
ทำความรู้จักกับ Software Design Patterns

ปัญหาในโค้ดเดิม (As-Is)
มีการอ่าน/เขียนไฟล์ data.json กระจัดกระจาย และใช้ตัวแปร global x
เสี่ยงต่อการแย่งกันใช้ข้อมูล (Race Condition) และข้อมูลไฟล์สูญหาย
การแก้ด้วย Singleton Pattern
ประกันว่า Class จัดการ Database/File Manager จะมีเพียง Single Instance เดียวตลอดวงจรระบบ
สร้าง Global Point of Access ที่ปลอดภัย ควบคุมผ่าน getInstance()
TO-BE ARCHITECTURAL PATTERN 1 SINGLETON PATTERN
Design Pattern เป้าหมาย 1: Singleton

Abstraction Layer: คั่นกลางระหว่าง Business Logic และ Data Access Layer
Clean Methods: เรียกใช้ add_product(), get_all() โดยไม่สนใจว่าเก็บใน JSON หรือ SQL
