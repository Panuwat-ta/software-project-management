รายวิชา ENGSE202: การจัดการโครงการซอฟต์แวร์ (Software Project Management)
คำชี้แจง: ตอบคำถามอัตนัยต่อไปนี้ โดยใช้องค์ความรู้การบริหารจัดการโครงการสากล (PMBOK Guide / Agile) ในการวิเคราะห์และแก้ไขปัญหา (ข้อละ 10 คะแนน รวม 50 คะแนน)
ข้อที่ 1: โครงการ Brownfield, Project Charter และ WBS (สัปดาห์ที่ 1 - 2)
1.1 การบริหารจัดการขอบเขต (Scope Management) ในโครงการปรับปรุงซอฟต์แวร์เดิม (Brownfield Project) มีความท้าทายแตกต่างจากโครงการเริ่มใหม่จากศูนย์ (Greenfield Project) อย่างไร? เหตุใดจึงมักเกิด "ขอบเขตซ่อนเร้น (Hidden Scope)"?
1.2 Work Breakdown Structure (WBS) คืออะไร? จงเขียนโครงสร้าง WBS ลำดับชั้น (อย่างน้อย 3 ระดับ) สำหรับโจทย์ "การปรับปรุงระบบคลังสินค้า v1.1 เพื่อเพิ่มระบบสมาชิกลดราคา" โดยต้องครอบคลุมทั้งงานฝั่งเทคนิค (เช่น การแกะโค้ด/Refactoring) และงานฝั่งบริหารจัดการ
ข้อที่ 2: การบริหารความเสี่ยงทางเทคนิค และ Risk Matrix (สัปดาห์ที่ 2)
2.1 จงอธิบายความแตกต่างระหว่างความเสี่ยงประเภท Known-Unknowns และ Unknown-Unknowns ในโครงการซอฟต์แวร์ Legacy และเหตุใดการประเมินเวลาในโครงการ Brownfield จึงต้องมีการคูณค่าเผื่อความเสี่ยง (Buffer) 1.5x - 2.0x?
2.2 หากทีมระบุความเสี่ยงว่า "การแก้ไขฟังก์ชันลดสต็อกสินค้า อาจส่งผลข้างเคียงให้ฟังก์ชันคำนวณมูลค่ารวมคลังสินค้าคำนวณผิดพลาด (High Risk)" จงเสนอ แผนบรรเทาความเสี่ยง (Mitigation Plan) เชิงรุกที่มีความเป็นไปได้ทางการบริหารและการปฏิบัติจริงมา 2 ข้อ
ข้อที่ 3: RACI Matrix, Communication Management และ Agile Sync (สัปดาห์ที่ 3 & 6)
3.1 RACI Matrix คืออะไร? จงอธิบายความหมายของตัวอักษร R, A, C, I และเหตุใดใน 1 กิจกรรมจึงต้องกำหนดให้มีผู้รับผิดชอบหลัก A (Accountable) เพียงคนเดียวเท่านั้น?
3.2 จงอธิบายสูตรคำนวณช่องทางการสื่อสาร (c = n(n-1)/2) และตอบคำถามว่า เหตุใดการสื่อสารในทีมที่ไร้ระเบียบจึงสร้าง Communication Overhead Cost? พร้อมทั้งเสนอแนวทางการใช้ Communication Matrix และ Daily Standup 15 นาที เพื่อแก้ปัญหานี้
ข้อที่ 4: การประมาณการต้นทุน และ Cost Baselining (สัปดาห์ที่ 5 & 7)
4.1 จงอธิบายความแตกต่างระหว่างเทคนิคการประมาณการต้นทุนแบบ Analogous Estimating และ Bottom-up Estimating พร้อมระบุว่าเหตุใด Bottom-up Estimating จึงมีความแม่นยำสูงกว่าในงานปรับปรุงโครงสร้างซอฟต์แวร์ (Refactoring)?
4.2 จงอธิบายองค์ประกอบของ Total Estimated Project Cost ซึ่งประกอบไปด้วย Direct Labor Cost, Infrastructure/Tooling Cost, และ Contingency Reserve พร้อมระบุเกณฑ์การแจ้งเตือนงบประมาณ Cost Variance Thresholds (เขียว, เหลือง, แดง) ว่า PM ต้องควบคุมอย่างไรเมื่อเกิดสภาวะ Over Budget
ข้อที่ 5: Quality Gates, Definition of Done (DoD) และ Phase Gate Review (สัปดาห์ที่ 3, 6 & 7)
5.1 Quality Gate บนบอร์ด Jira/Trello คืออะไร? และความสัมพันธ์ระหว่าง Definition of Ready (DoR) กับ Definition of Done (DoD) ช่วยสกัดกั้นโค้ดที่ไม่มีคุณภาพไม่ให้หลุดไปถึงมือลูกค้าได้อย่างไร? จงยกตัวอย่างเช็คลิสต์ DoD ของทีมมา 3 ข้อ
5.2 Phase Gate Review (Tollgate) คืออะไร? จงอธิบายบทบาทของ Project Manager และ Project Sponsor (อาจารย์/ลูกค้า) ในกระบวนการ Sign-off ผ่านด่านเฟสที่ 2 เพื่ออนุญาตให้ทีมกดปุ่ม "Start Sprint 1" เข้าสู่ภาคการเขียนโค้ดจริงในครึ่งเทอมหลัง
