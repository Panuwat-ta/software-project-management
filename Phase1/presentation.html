1. เป้าหมายโครงการ (Project Objectives)

🛡️ ปรับปรุงเสถียรภาพ (Stability)

ทำให้ระบบจัดการสินค้ามีความทนทานต่อข้อผิดพลาด ไม่หยุดทำงานจากการรับข้อมูลที่ไม่ถูกต้อง (Crash Prevention)

⚙️ โครงสร้างโค้ด (Refactoring)

ทำความสะอาดโค้ดเดิม ยุบส่วนซ้ำซ้อน แยกฟังก์ชันเป็นโมดูลให้ชัดเจน (Modularized)

💾 ความสมบูรณ์ของข้อมูล (Data Integrity)

ปรับปรุงฟังก์ชันการบันทึกฐานข้อมูล JSON ให้ปลอดภัย ป้องกันความเสี่ยงจากข้อมูลสูญหาย

🧪 ระบบทดสอบ (Automated Testing)

จัดทำชุดทดสอบเพื่อให้มั่นใจว่าการปรับปรุงจะไม่ส่งผลเสียต่อการทำงานที่มีอยู่ (Regression Testing)

2. ขอบเขตการทำงาน (Final Scope - WBS)

แบ่งขอบเขตการทำงานออกเป็น 4 เฟสหลัก เพื่อประกันความเสถียรและป้องกันซอฟต์แวร์แครช

Phase 1: Refactoring & Infrastructure

  • แยกไฟล์ฐานข้อมูล members.json
  • ใช้ Class (OOP) แทนตัวแปร Global
  • ยุบตรรกะที่ซ้ำซ้อน

Phase 2: Member Database Integration

  • กำหนดโครงสร้างข้อมูลสมาชิก
  • สร้างเมธอดเพิ่ม/ค้นหา/บันทึก (LOAD/SAVE)
  • ใช้ Safe Atomic Write

Phase 3: Discount & Checkout Engine

  • พัฒนาระบบรับข้อมูลการจ่ายยอด
  • ตรรกะคำนวณส่วนลด (Discount Logic)
  • แสดงผลบิลก่อนหักสต็อก

Phase 4: Exception Handling & QA

  • ดักจับ Input แปลกปลอม
  • ทำ Graceful Degradation
  • พัฒนา Unit Tests สำหรับการคำนวณ

3. ตารางแผนเวลาและเครื่องมือ (Time Schedule)

ใช้ Trello (Kanban Board) ในการติดตาม: Backlog, To Do, In Progress, Review, Done

4. การวิเคราะห์ความเสี่ยง (Risk Matrix)

ความเสี่ยง (Risk) ผลกระทบ (Impact) แผนบรรเทา (Mitigation)
Global State Conflict ข้อมูลถูกเขียนทับ, คำนวณพลาด แปลงระบบเป็น OOP (MVC Pattern) แยก Business Logic ออกจาก CLI
Data Corruption ข้อมูลหายหากแอปค้าง/ไฟดับขณะ save ใช้ Atomic Write หรือ SQLite มั่นใจบันทึกสมบูรณ์ 100%
Input Type Mismatch ValueError แล้วระบบล่ม บังคับใช้ Input Validation ดักจับด้วย try-except ก่อนประมวลผล
Encoding Risk ภาษาไทยเพี้ยน ตั้งค่า UTF-8 เสมอ ในการอ่าน/เขียนไฟล์

6. จุดล็อกเกราะป้องกัน (Automated Testing)

การใช้ PyTest เป็นเกราะป้องกันไม่ให้จุดบกพร่องเก่ากลับมา (Regression Prevention)

import pytest
from app import InventoryManager, Product

def test_cut_stock_success(manager):
    """ทดสอบการหักสต็อกสำเร็จเมื่อมีสินค้าพอเพียง (Happy Path)"""
    success, msg, remaining = manager.cut_stock("1", 5)
    assert success is True
    assert remaining == 15

def test_cut_stock_not_enough(manager):
    """ทดสอบการหักสต็อกล้มเหลวเมื่อยอดเบิกเกินสต็อก (Edge Case)"""
    success, msg, remaining = manager.cut_stock("2", 15)
    assert success is False
    assert msg == "Error: Not enough stock!"

def test_cut_stock_not_found(manager):
    """ทดสอบการตัดสต็อกด้วย ID ที่ไม่มีในระบบ (Edge Case ดัก Error)"""
    success, msg, remaining = manager.cut_stock("999", 5)
    assert success is False
    assert msg == "Product not found!"
