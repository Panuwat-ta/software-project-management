Refactoring (Noun & Verb)
Noun: การปรับเปลี่ยนโครงสร้างภายในซอฟต์แวร์เพื่อให้อ่านและแก้ไขง่ายขึ้น โดยไม่กระทบพฤติกรรมภายนอก
Verb: การปรับแต่งโค้ดด้วยเทคนิคย่อยสลับกับการรัน Unit Test ถี่ๆ
ข้อแตกต่างสำคัญ
Refactoring: โครงสร้างใหม่ ➔ พฤติกรรมภายนอกเท่าเดิม 🟢
Bug Fixing: แก้ไขพฤติกรรมที่ผิดให้ถูกต้อง 🔵
Feature Addition: เพิ่มพฤติกรรมและความต้องการใหม่ 🟣

1. Rename Variable
เปลี่ยนชื่อตัวแปรและเมธอดลึกลับ (x, a, b) ให้สื่อเจตนา (Clean Naming)
2. Extract Function
สับฟังก์ชันยักษ์ main() ออกเป็นฟังก์ชันย่อยที่มีหน้าที่เดียว (Single Responsibility)
3. Extract Class
แยกโครงสร้างข้อมูลและพฤติกรรมออกเป็น Class (Product, Repository, Service)
4. Encapsulate Field
ขจัดตัวแปร Global x โดยส่งผ่าน Object Instance ด้วย Dependency Injection
