Definition of Ready (DoR) คืออะไร?
ข้อตกลงว่า งาน 1 ชิ้นใน Backlog มีข้อมูลสมบูรณ์ "พร้อม" ที่จะให้นักพัฒนาดึงไปทำใน Sprint หรือยัง เพื่อป้องกันการหยิบงานที่ไม่ชัดเจนมาทำ
เช็คลิสต์ DoR ตัวอย่าง
Description อธิบายความต้องการชัดเจน
มีการประเมินเวลา (Original Estimate / Story Points)
ระบุผู้รับผิดชอบ (Assignee) ตาม RACI Matrix
ระบุความเสี่ยงเชิงเทคนิคที่เกี่ยวข้องชัดเจน
QUALITY CONTROL CHECKPOINT 1 DEFINITION OF READY (DOR)
การควบคุมคุณภาพด้วย DoR

ข้อตกลงว่า งาน 1 ชิ้นสมบูรณ์ "เสร็จสิ้น" จนย้ายไปช่อง Done ได้แล้วจริงๆ:
โค้ดผ่าน Peer Code Review และได้คำอนุมัติ (Approve) บน GitHub
ชุดทดสอบอัตโนมัติ PyTest ผ่านไฟเขียว 100% บน CI/CD
โค้ดถูก Merge เข้าสาย develop เรียบร้อย
บันทึก Log Time เวลาทำงานจริงลงบน Jira
QUALITY CONTROL CHECKPOINT 2 DEFINITION OF DONE (DOD)
การควบคุมคุณภาพด้วย DoD

ไร้คนคอยขยับการ์ด
เราจะไม่ใช้ "คน" นั่งขยับเปลี่ยนสถานะการ์ดบน Jira แต่ใช้ Jira Automation Rules เชื่อมต่อกับ GitHub Events เพื่อเลื่อนช่องทางแบบ Real-time
โครงสร้าง Automation Rule
WHEN (เมื่อเกิดเหตุการณ์):
GitHub Pull Request is created
THEN (ให้ทำสิ่งนี้):
Move Jira Issue status to Code Review
AUTOMATED PROJECT GOVERNANCE JIRA AUTOMATION RULES CONCEPT
การตั้ง Quality Gates ด้วย Jira Automation

Rule 1: Start Work
เมื่อมีการสร้าง Branch บน GitHub ➔ ย้ายการ์ด Jira จาก To Do ไป In Progress
Rule 2: Review Gate
เมื่อมีการเปิด Pull Request บน GitHub ➔ ย้ายการ์ด Jira ไป Code Review
Rule 3: Auto Close
เมื่อ Pull Request ถูก Merge เข้า develop ➔ ย้ายการ์ด Jira ไป Done อัตโนมัติ

PROJECT FINANCIAL GOVERNANCE TIME LOG & COST TRACKING

สูตรคำนวณ Cost Variance:
CV > 0 (บวก): Under Budget 🟢 (ใช้เงินน้อยกว่าแผน)
CV = 0: On Budget 🟡 (เป็นไปตามแผน)
CV < 0 (ลบ): Over Budget 🔴 (ใช้เงินเกินงบ ต้องระวัง!)
EARNED VALUE MANAGEMENT COST VARIANCE (CV) ANALYSIS
การวิเคราะห์ Cost Variance (CV)

รายการวิเคราะห์
รายละเอียดชิ้นงาน (Task 2.1 Refactoring)
มูลค่าคำนวณทางการเงิน
Planned Cost
ตั้งงบไว้ 8 ชม. (Senior Dev Rate 400 บาท/ชม.)
3,200 บาท
Earned Value (EV)
Senior Dev ทำงานเสร็จสมบูรณ์ 100%
3,200 บาท
Actual Cost (AC)
ใช้เวลาจริงไป 12 ชม. เพราะเจอโค้ดซ่อนเร้น (12 $\times$ 400)
4,800 บาท
Cost Variance (CV)
$CV = EV - AC = 3,200 - 4,800$
-1,600 บาท (Over Budget 🔴)
